SKILL.md body (8 sections, analyst/associate voice — quantitative, not decision-making):

**Step 1: Input Gathering** — Ask ALL in ONE message:
1. Fund name, vintage year, fund size, and current period (e.g., "Q3 2025 / Year 4 of 10")
2. Fund-level metrics: Capital called %, DPI, TVPI, IRR (or "calculating from portfolio data")
3. Portfolio: List of companies with current valuations + any follow-ons in the quarter
4. Distributions in period: Any exits, secondaries, or partial realizations?
5. Pacing: How much dry powder remains? Is fund on pace vs deployment plan?
6. Market context points: Any notable macro events the LP should understand this quarter?
7. LP audience type: Institutional (ILPA-compliant format) / Family office (simplified) / Mixed

**Step 2: Apply Frameworks** — Read references/portfolio-report-template.md BEFORE generating. Apply:
- ILPA Reporting Template: Read @shared/frameworks/ilpa-standards.md for TVPI, DPI, RVPI, IRR, MOIC definitions
  Source: https://ilpa.org/reporting-template/
- Visible.vc LP reporting structure: https://visible.vc/blog/lp-reporting/
- Carta analytics benchmarks for vintage contextualization

**Step 3: Workflow** — Execute in order:
1. Confirm LP audience type → adjust detail level (ILPA full vs simplified)
2. Calculate or confirm fund-level metrics (TVPI, DPI, RVPI, IRR)
3. Build portfolio summary table with all active companies
4. Identify top 3-5 performers (metric evidence required — not just "doing well")
5. Identify watch list companies (specific risk flags — not generic "monitoring")
6. Summarize distributions and realizations in period (or "none this period")
7. Assess pacing vs deployment plan
8. Add market context box (3-5 bullet points max — not an essay)
9. List next quarter priorities (specific — not "continue monitoring")
10. Output using TEMPLATES.md structure

**Step 4: Output Format** — ALWAYS use TEMPLATES.md structure (8 sections of LP quarterly report).

**Step 5: LATAM Fund Context** — Read references/latam-fund-context.md:
- LATAM LP base is primarily family offices — ILPA-full compliance is institutional standard, but many LATAM family office LPs want simpler reporting. Adjust based on LP audience.
- LATAM fund context in market section: always include LATAM VC market context (Cuantico/LAVCA figures) — LPs want to know how the LATAM market is performing relative to fund activity.
- Distribution expectations: LATAM exit environment is thin — manage LP expectations on DPI timeline. Most LATAM fund I distributions come from secondaries or M&A, rarely IPO.
- Carta benchmarks for context: Label "(US-sourced benchmark, Carta Q1 2026)" — explain LATAM performance typically lags US at same vintage.

**Tone & Editorial Voice** — See @shared/frameworks/editorial-voice.md. Analyst voice — precise, data-driven, no spin. Watch list companies get honest assessment: "GrowthCo is burning $120k/month against $85k/month projected. Bridge required within 90 days absent revenue acceleration. Risk: high." Not: "GrowthCo is facing some challenges but the team is working hard."

**Step 6: Próximos Pasos** — Next quarter priorities for the fund, specific and action-oriented.

name: fund-performance-analyzer

metadata:

SKILL.md body (8 sections, analyst/associate voice):

**Step 1: Input Gathering** — Ask ALL in ONE message:
1. Fund name and vintage year (required — all benchmarks are vintage-specific)
2. Capital called to date ($) and total committed capital ($)
3. Total distributions to LPs to date ($)
4. Current portfolio fair market value (FMV) — sum of all portfolio company valuations
5. Number of portfolio companies: total / active / exited
6. Date of analysis (for IRR calculation date basis)
7. Public market benchmark for PME: S&P 500 / Russell 2000 / MSCI EM (select one or state "skip PME")

**Step 2: Apply Frameworks** — Read references/fund-benchmarks.md BEFORE calculating. Apply:
- Carta Fund Performance Report Q1 2026 (PRIMARY source — real benchmarks by vintage)
  These are US-domiciled funds only. See references/latam-fund-context.md for LATAM context.
- Cambridge Associates VC benchmark methodology: https://www.cambridgeassociates.com/insight/venture-capital-benchmark-commentary/
- Kauffman Foundation VC returns analysis: https://www.kauffman.org/wp-content/uploads/2019/12/investment_myths_lies_and_truth_about_vc_kauffman_fellowship.pdf
- ILPA metric definitions: Read @shared/frameworks/ilpa-standards.md

**Step 3: Workflow** — Execute in order:
1. Calculate all 6 metrics using inputs provided:
   a. TVPI = (Total Distributions + Current FMV) ÷ Capital Called
   b. DPI = Total Distributions ÷ Capital Called
   c. RVPI = Current FMV ÷ Capital Called [TVPI - DPI]
   d. MOIC = (Realized + Unrealized Value) ÷ Invested Capital [equivalent to TVPI when fully called]
   e. Net IRR = IRR of cash flows (calls as negative, distributions + FMV as positive terminal value)
   f. PME = If public market selected: compare net IRR to equivalent buy-and-hold index return
2. Look up vintage benchmarks from references/fund-benchmarks.md
3. Position fund at percentile: below median / median / 75th percentile / top decile
4. Attribution analysis: Which 3 companies drive TVPI? DPI vs RVPI split (realized vs unrealized)?
5. Reserve analysis: How much dry powder vs reserve needed for follow-ons?
6. Apply LATAM fund context from references/latam-fund-context.md
7. Output using TEMPLATES.md structure

**Step 4: Output Format** — ALWAYS use TEMPLATES.md structure:
- Fund metrics calculation table (6 metrics with inputs and results)
- Vintage benchmark comparison table (your fund vs Carta percentiles for your vintage)
- Percentile placement summary
- Attribution analysis (top 3 positions by TVPI contribution)
- DPI vs RVPI split with interpretation
- Reserve analysis
- LATAM Fund Context box
- Próximos Pasos

**Step 5: LATAM Fund Context** — Read references/latam-fund-context.md:
- CRITICAL: Carta benchmarks are US-domiciled funds ONLY. LATAM fund performance is NOT directly comparable.
- LATAM performance discount: Typically 30-50% below US equivalents at same vintage due to: longer exit timelines (LATAM M&A slower), thinner secondary market, fewer Series A+ funds to drive markups.
- Label ALL Carta figures: "(US-sourced benchmark, Carta Q1 2026)"
- LATAM context note: "No equivalent LATAM fund performance database exists at Carta scale. LAVCA tracks headline data; Preqin has limited LATAM coverage."

**Tone & Editorial Voice** — See @shared/frameworks/editorial-voice.md. Analyst voice — precise, no rounding that changes interpretation. If IRR is 4.2%, say 4.2% — not "mid-single digits." If below median, say "below median (7th percentile for 2021 vintage at Carta)."

**Step 6: Próximos Pasos** — Focus on actionable analysis conclusions: reserve allocation decisions, LP communication messaging based on benchmark position, portfolio triage based on attribution.

**Sources** — Carta Q1 2026: references/fund-benchmarks.md | Cambridge Associates: https://www.cambridgeassociates.com/insight/venture-capital-benchmark-commentary/ | Kauffman: https://www.kauffman.org/wp-content/uploads/2019/12/investment_myths_lies_and_truth_about_vc_kauffman_fellowship.pdf | @shared/frameworks/ilpa-standards.md
